# @warpstate/webmcp

WebMCP tools that let AI agents capture and load warpstate snapshots in a running app.

Part of [warpstate](https://github.com/tiagokall/warpstate): open your React app directly in the exact state of a test scenario. See the [main README](https://github.com/tiagokall/warpstate#readme) for the quickstart and API reference.
